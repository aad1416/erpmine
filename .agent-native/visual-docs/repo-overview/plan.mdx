# IMAP/SMTP Mailbox Adapter

A second Connection Method beside the Gmail API adapter (ADR 0002): a Mailbox is read over IMAP and answered over SMTP, logging in with an app password. Each Mailbox uses exactly one Connection Method. Built on branch `feat/imap-smtp-adapter` in six tickets (`.scratch/imap-smtp-adapter/issues/`).

Manifest: `../../../agent-native.json`

`imap_thread_messages` is new and IMAP-only: unique on (`source_id`, `message_id`), indexed on (`source_id`, `conversation_id`), and never purged, so a Conversation older than the outbox's 7-day retention still threads. `direction` is `inbound` or `outbound`. The other two tables are shared with every adapter and unchanged; the relations are by `source_id`, not foreign keys.
