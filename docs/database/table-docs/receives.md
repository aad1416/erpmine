# `receives`

## Searchable Aliases
material receiving, stock intake, warehouse entry, inbound shipment, goods received

## Description
The `receives` table acts as the **Warehouse Voucher** for the physical arrival of goods. When a shipment arrives from a vendor, the warehouse staff creates a Receiving Record to acknowledge that a delivery has taken place. 

This table serves as the audit link between the "Contractual Purchase" (the PO) and the "Physical Inventory" (the stock on the shelf). Every time a Receiving Voucher is finalized, the system automatically updates the `received_quantity` on the related Purchase Order and increases the stock levels in the warehouse.

## ⚙️ The Stock Entry Workflow
1.  **Arrival**: A delivery truck arrives at the warehouse dock.
2.  **Voucher Creation**: Staff creates a `receives` record, linking it to the specific `purchase_order_id`.
3.  **Verification**: The employee (`received_by_name`) counts the items and matching them against the packing slip.
4.  **Finalization**: Once the `received_at` date is set, the system officially adds the items to the inventory and creates a valuation record in `fifo_reports`.

## ⚠️ SQL-Critical Behaviors
- **Permanent Audit Record**: Once a Receive record is processed, it creates a historical record of "What entered the building." 
- **Header-to-Detail**: One `receives` header can contain multiple `receive_line_items`, each tracking a different SKU from the same shipment.
- **PO Synchronization**: The system uses the `purchase_order_number` to cross-reference the shipment for the accounting department, ensuring they only pay for what was actually delivered.

## Common Query Patterns
```sql
-- Find all receiving vouchers for a specific Purchase Order
SELECT number, received_by_name, received_at 
FROM receives 
WHERE purchase_order_number = 'PO-1025';

-- Audit the receiving volume of a specific staff member
SELECT received_by_name, COUNT(id) 
FROM receives 
GROUP BY received_by_name;
```
