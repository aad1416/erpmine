# `notificaitons`

## Searchable Aliases
alerts, system messages, push notifications, bell icons, popups, event logs

> [!IMPORTANT]
> **Table Naming Note**: This table contains an intentional typo in the database schema (`notificaitons` instead of `notifications`). All technical queries and code references MUST use this specific spelling.

## Description
The `notificaitons` table is the **System Alert Registry** for the **Lyndom** (the current PostgreSQL ERP) environment. It serves as the master ledger for in-app alerts, broadcast messages, and system-status updates generated by the server. 

Whether a user is being alerted about a completed bulk import, a low-stock warning, or a company-wide announcement, the content and targeting logic are stored here.

## ⚙️ The Notification Broadcast Workflow
1.  **Event Trigger**: A system event (e.g., an error during a long-running job) causes a record to be created here.
2.  **Audience Selection**: The `audience` field determines the scope (e.g., `GLOBAL`, `STORE`, `SINGLE_USER`). 
3.  **Content Design**: The `title`, `text`, and optional `logo` (icon) are defined.
4.  **Action Linkage**: The `redirect` and `urls` fields provide the user with a clickable path to resolve the alert (e.g., "Go to Error Log").
5.  **Delivery**: The `notificaiton_user` table tracks the individual delivery and "seen" status for each targeted user.

## ⚠️ SQL-Critical Behaviors
- **Broadcast Scoping**: If the `audience` is `STORE`, the `target_store_id` must be populated to limit the message to that specific branch.
- **Visual Feedback Logic**: The `progress` integer allows for "Live Progress Bars" in the UI (0–100), and `is_error` triggers a high-visibility (Red) alerting state.
- **Traceability**: The `date` on this record is the "Human Readable" event timestamp, stored as a BigInt.

## Enums Used
### `notificaiton_audience_enum`
- `GLOBAL`: Every user in the system.
- `STORE`: All users assigned to a specific `target_store_id`.
- `SINGLE_USER`: Targeted to one specific individual.
- `MULTIPLE_USERS`: Targeted to a select group of users.

## Common Query Patterns
```sql
-- List all active "Global" alerts for the dashboard
SELECT title, text 
FROM notificaitons 
WHERE audience = 'GLOBAL' AND is_active = true 
ORDER BY date DESC;

-- Identify failing technical processes (alerts with progress < 100 and is_error = true)
SELECT title, progress 
FROM notificaitons 
WHERE is_error = true AND progress < 100;
```
