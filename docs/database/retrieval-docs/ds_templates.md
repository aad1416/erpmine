# ds_templates

## Purpose
The global design blueprint for the digital storefront. It acts as the master repository for website themes and UI blueprints that define the visual and structural identity of the public e-commerce site across all branches.

---

## Retrieve This Table When The User Asks About

**Website themes and storefront layouts**
UI blueprints or site styles. Identifying the core page structure (Home, Catalog, Product) for a specific theme type (e.g., Retail vs. Wholesale).

**Theme management and global design**
Finding all active themes available for store adoption. Identifying the most complex templates based on the number of UI widgets and page components (page manifest).

**Layout inheritance**
Auditing the master page blueprints that drive the look and feel of "Subscribing" store branches.
