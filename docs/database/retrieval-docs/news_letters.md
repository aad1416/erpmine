# news_letters

## Purpose
The mass-communication command center. It manages the drafting and metadata for broadcast email campaigns, including newsletters and marketing blasts, allowing branches to manage proactive outbound messaging to their regional audience.

---

## Retrieve This Table When The User Asks About

**Email campaigns and newsletters**
Marketing blasts or subscriber updates. Listing active campaigns for a specific store, sorted by date.

**Campaign content and design**
Retrieving the public email subject line vs. the internal title. Auditing the HTML or text body of a specific announcement.

**Communication scheduling**
Finding campaigns created by a specific user or within a certain timeframe. Identifying the scheduled release date (Epoch) for a bulletin.

---

## Co-Retrieved Sibling Tables
- `news_letter_files` — supplemental documents or PDF attachments for the campaign.
- `news_letter_view_reports` — the analytics and delivery engagement logs.
- `stores` — the branch managing the communication.
- `users` — the marketing user who designed the campaign.
