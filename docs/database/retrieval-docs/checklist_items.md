# checklist_items

## Purpose
The actionable tasks within a Quality Control blueprint. It defines the granular steps—such as physical damage checks or cable verification—that must be performed during critical warehouse or technical events.

---

## Retrieve This Table When The User Asks About

**Actionable verification steps and tasks**
Granular inspection requirements, quality control points, or individual procedural steps. Finding the "How-To" instructions and criteria for a specific check.

**QA progress tracking**
Identifying which individual tasks (e.g., "Check for physical damage") are part of a larger quality procedure. Tracking the operational integrity of verification steps.
