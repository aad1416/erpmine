# mikro_orm_migrations

## Purpose
The technical version control ledger. It tracks the chronological history of structural changes made to the database schema—such as new tables or columns—ensuring that the application code remains in sync with the database structure.

---

## Retrieve This Table When The User Asks About

**Database updates and schema changes**
Migration scripts or system versioning. Listing the most recent structural changes applied to the database.

**System technical audit**
Verifying the exact moment a specific feature or technical "Evolution" was added to the system (executed_at). Identifying the current database version.
