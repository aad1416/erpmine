# checklists

## Purpose
The Quality Control template registry. It defines high-level blueprints for verification processes—such as packaging audits or technical inspections—that are reused across warehouse, service, and receiving departments.

---

## Retrieve This Table When The User Asks About

**Quality control templates and protocols**
Inspection blueprints, procedural verification forms, or standard audit protocols. Identifying the high-level quality standards for a branch (e.g., "Safety Verification").

**Standardization of procedures**
Finding the active procedures used to enforce operational standards. Organizing the sequence of inspections in the management interface.
