# ds_nav_bar

## Purpose
The header configuration registry. It controls the structure and features of the storefront's primary navigation menu, using a multi-zone approach to manage search bars, login sections, category trees, and custom links independently for each branch.

---

## Retrieve This Table When The User Asks About

**Website header and navigation menu**
Top bar, menu links, or site navigation. Retrieving the navigation schema (Zones) for a specific store’s e-commerce site.

**Header feature toggles**
Identifying stores that have enabled or disabled specific UI features, such as the search bar or the shopping cart.

**Custom pathing and site-map**
Finding the hierarchical category menu or custom primary navigation URLs (e.g., "About Us") for a branch.
