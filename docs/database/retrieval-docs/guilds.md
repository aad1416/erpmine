# guilds

## Purpose
The global industry and franchise association registry. It defines high-level associations or communities—such as "Power Emergency"—that stores can join to share catalog standards and collaborative logic across the enterprise.

---

## Retrieve This Table When The User Asks About

**Industry groups and associations**
Franchise networks or specialized trade groups. Identifying the global grouping mechanisms that link independent business branches.

**Cross-store membership and sharing**
Finding all active guilds in the system. Identifying the system-wide associations that allow for shared catalog visibility and industry standards.
