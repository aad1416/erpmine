# production_instruction_sets

## Purpose
The methodology blueprint. It acts as the master container for standardized engineering procedures and assembly-line manuals (SOPs), ensuring consistent technical guidance across the organization.

---

## Retrieve This Table When The User Asks About

**Technical manuals and assembly procedures**
Manufacturing guides, SOP names, or assembly methodology blueprints. Identifying the high-level category of technical work (e.g., "Final Quality Audit").

**Standard Operating Procedure (SOP) governance**
Finding the active procedures used to enforce methodology standards across different departments (e.g., Electrical vs. Wiring). Identifying which manuals are set to "Auto-Generate" for new builds.

---

## Co-Retrieved Sibling Tables
- `instructions` — the individual manual steps inside the blueprint.
- `production_instruction_set_specs` — the rules that auto-assign these manuals to products.
- `departments` — the team responsible for following the instructions.
- `users` — the engineer who designed the SOP.
