# option_selector_sources

## Purpose
The technical selection inputs. It defines the criteria required to trigger an automated product upgrade, monitoring the specifications of a "Base Item" to identify when an upgrade rule should be activated.

---

## Retrieve This Table When The User Asks About

**Selection inputs and configuration sources**
Trigger criteria for automated upgrades. Identifying the technical choices (e.g., "Environment: Outdoor") on a base product that drive the inclusion of necessary physical add-ons.

**Dependency chains in sales**
Mapping product categories and specifications to specific upgrade rules. Finding if a technical selection on a quote triggers an automated option.
