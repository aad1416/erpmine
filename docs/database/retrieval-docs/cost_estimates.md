# cost_estimates

## Purpose
The pre-sales financial sandbox. It allows estimators and engineers to model the total expected cost and technical scope of a project or assembly before generating a formal commercial proposal or quote.

---

## Retrieve This Table When The User Asks About

**Quotes, bids, and financial projections**
Budgeting, proposals, or pricing models. Retrieving the total modeled cost and label for a specific internal project or customer bid.

**Feasibility studies and internal budgeting**
Identifying high-value "draft" projects or technical feasibility models. Finding all active budgets created by a specific estimator.

---

## Co-Retrieved Sibling Tables
- `cost_estimate_specs` — the granular technical requirements that drive the total cost.
- `stores` — the branch managing the project model.
- `users` — the manager or estimator who developed the model.
