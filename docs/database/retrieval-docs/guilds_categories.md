# guilds_categories

## Purpose
The community classification and catalog filter. it defines the visibility of product categories for specific industry guilds, ensuring that stores (e.g., in "Power Systems") see a tailored catalog relevant to their specialized trade.

---

## Retrieve This Table When The User Asks About

**Guild groups and interest categories**
Community-level product classification. Identifying all technical categories accessible to a specific industry group.

**Tailored catalog experiences**
Auditing the rules that restrict or enable certain taxonomies (e.g., high-voltage equipment) for specific guild members.
