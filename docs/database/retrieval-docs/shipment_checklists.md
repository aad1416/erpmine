# shipment_checklists

## Purpose
The Quality Control (QC) junction for logistics. It links physical units inside a shipment to their specific technical or packaging requirements, ensuring that every asset is verified and cleared before dispatch.

---

## Retrieve This Table When The User Asks About

**Shipping quality control and verification**
Packing verification, shipping QC audits, or pre-shipment inspections. Ensuring technical equipment meets company standards before leaving the warehouse.

**Technical inspection proof**
Identifying exactly which mandatory QC steps (e.g., Calibration Check) were performed for a specific serial number. Tracking the progression of warehouse loading protocols and loading verification.

---

## Co-Retrieved Sibling Tables
- `shipment_line_items` — the specific physical unit being inspected.
- `checklist_items` — the technical requirement or QC rule being fulfilled.
