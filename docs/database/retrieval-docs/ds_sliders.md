# ds_sliders

## Purpose
The promotional carousel registry. It manages the high-impact hero banners and home page images that appear on the storefront, allowing marketing teams to curate the sequence and call-to-action for regional promotions.

---

## Retrieve This Table When The User Asks About

**Banners and carousels**
Home page images or promotional slideshows. Retrieving the active carousel manifest for a specific store, sorted by priority (order).

**Marketing call-to-action (CTA)**
Finding the destination URLs (related links) and marketing copy for specific hero banners. Identifying branches with no active homepage promotions.

**Seasonal scheduling**
Finding active vs. disabled promotions for a branch office. Auditing the sequence of rotation for storefront graphics.

---
