# item_specifications

## Purpose
The global technical profile (Blueprint) for a product. it stores the engineering values and datasheet details assigned to an item master, providing a "One Source of Truth" for technical documentation across the system.

---

## Retrieve This Table When The User Asks About

**Global technical datasheet and DNA**
Technical specs, product attributes, or engineering details for a product blueprint. Finding global technical answers (e.g., "Number of Batteries") for a specific item.

**Engineering criteria and search**
Finding all products matching a specific global technical criteria (e.g., "Indoor" type or "277 VAC"). 

**Technical units and documentation**
Retrieving technical values and their associated units (e.g., Hz, VAC, lbs) for generating submittal packages or product manuals. 

---

## Co-Retrieved Sibling Tables
- `items` — the global product blueprint being specified.
- `specifications` — the technical questions (attributes) being answered.
